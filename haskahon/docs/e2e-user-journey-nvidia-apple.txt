Failure diagnosis and repair summary
1. Active jobs were being marked failed whenever the database module loaded,
   which could happen during a development reload. That import-time mutation
   was removed.
2. The personalization validator required an exact AI-generated label match and
   falsely rejected otherwise valid scripts at 48%. Labels are now normalized
   to canonical portfolio symbols, and unmatched display metadata falls back to
   a general classification instead of killing the podcast.
3. Active generation jobs are now tracked and can restart from their saved
   SQLite profile snapshot after a real server restart.
4. The progress screen now reconnects and resumes polling after temporary
   network errors.
5. The application now assembles the chapter recordings into one final
   podcast.mp3 while retaining the individual chapter MP3 files.
